# @ktvdung2812/tproxy

npm CLI wrapper for the [tproxy](https://github.com/ktvdung2812/TProxy) AI gateway.

## Install

```bash
npm install -g @ktvdung1606/tproxy
```

## Usage

```bash
tproxy --config config.yaml
```

When installed from npm, place a built `tproxy` binary next to the package or run from a local clone with `go run ./cmd/tproxy`.
